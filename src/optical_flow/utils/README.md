# utils

## Overview

Supporting helpers for optical flow processors. These modules are not primary flow
algorithms; they validate inputs and prepare images before computation.

## Components

| Component | Description |
| --------- | ----------- |
| [`preprocessor.py`](./preprocessor.py) | `OpticalFlowPreprocessor` image preprocessing helpers |
| [`validator.py`](./validator.py) | `OpticalFlowValidator` input validation helpers |
